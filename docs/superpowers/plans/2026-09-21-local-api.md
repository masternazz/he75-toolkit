# HE75 Local API Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an opt-in token-authenticated loopback API for local AI/debug integrations to inspect, preview, and explicitly apply saved profiles.

**Architecture:** `local_api.py` wraps `ThreadingHTTPServer` bound only to `127.0.0.1`; it delegates profile data to `ProfileStore` and hardware operations to `operations.py`. Settings own token creation and server lifecycle. The API has no arbitrary-command endpoint.

**Tech Stack:** Python 3.10+, `http.server`, `secrets`, tkinter, `unittest`, existing profile manager modules.

**Spec:** `docs/superpowers/specs/2026-09-21-profile-manager-design.md`

## Global Constraints

- Implement after the core profile-manager plan.
- Disabled by default; bind `127.0.0.1` only and never accept a host override.
- Require bearer authentication for every endpoint; never return the token from an endpoint.
- Writes require `confirm: true`, share board validation/locks/readback, and are logged redacted.
- No cloud service, LAN binding, shell execution, or arbitrary HID packet endpoint.
